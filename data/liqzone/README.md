# 清算帯推定データ(data/liqzone)

## 構成
- `raw/oi_5m|ohlcv_5m|liq_5m/YYYY-MM-DD.csv` : 生データ(5分足、UTC日別)。`src=bv` は Binance公開データ、`cv` は Coinalyze。仕様は仕様書(Claude Docs「清算帯推定｜データ収集・保存 仕様書」)
- `quality/` : 品質ログと通知状態
- `est/explore_<params_id>/` : 推定結果(派生物。`raw/` から再生成できる。`params.json` に使った設定)

## 期間の区分(`data/history/README.md` と同じ区分を使う)
| 区分 | 期間(UTC) | 使い方 |
|---|---|---|
| 探索 | 2024-10-01 〜 2025-09-30 | 自由に分析してよい |
| 確認 | 2025-10-01 〜 2026-04-30 | 事前登録した候補を1回だけ評価 |
| 最終確認 | 2026-05-01 〜 2026-09-01 | 確認を通過した候補を1回だけ評価 |
| 参考(既に見た期間) | 2026-09-02 〜 2026-10-26 | 検証には使わない |
| 前向き | 2026-10-27 以降 | 蓄積中。最後の関門 |

`scripts/liqzone_est.py` の `load_explore()` は探索期間しか返さない(ガード)。確認期間以降を読み込むのは、事前登録文書を作ったあとに限る。
