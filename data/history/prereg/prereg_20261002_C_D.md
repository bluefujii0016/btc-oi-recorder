## 1. 候補の由来

どちらも、探索期間(2024-10-01〜2025-09-30)の分析で見つけたもの。

- 15分足のSAR転換だけに従う方法は、エントリーのタイミングと決済方法をどう工夫しても、手数料後にマイナスだった(約1,100通りを比較)
- その中で、SAR以外の情報を組み合わせた次の2つだけが、前半・後半とも手数料後プラスになった
- どちらも総当たりで見つけたもので、日単位で見ると統計的には確立していない(探索期間の日単位の片側t検定:候補C p=0.078、候補D p=0.189)。確認期間では「方向が再現するか」を見る

## 4. 評価方法と合格基準

| 項目 | 内容 |
|---|---|
| 主指標 | 手数料(往復0.05%)控除後の期待値/回 |
| 合格基準(確認期間・最終確認期間で共通) | 手数料後の期待値 > 0、かつ期間を前半・後半に分けて両方で手数料後の期待値 > 0 |
| 前半・後半の境界 | 確認期間:2026-01-15 00:00 UTC。最終確認期間:2026-07-02 00:00 UTC |
| 参考指標(判定に使わない) | 日単位の片側t検定(最終確認期間では確認期間と合算した値も)、勝率。候補Cはロング側・ショート側の内訳。候補Dは上位10日が合計に占める割合と、SARと無関係に条件該当の全足でロングした場合の期待値 |
| 評価の順番 | 確認期間で1回だけ評価 → 合格した候補だけ最終確認期間で1回だけ評価 → 両方に合格した候補だけ前向き検証へ |
| 不合格の扱い | その候補は打ち切る。確認期間・最終確認期間のデータを見ながら閾値や決済方法を調整し直さない |
| エントリーしない期間 | データ開始から7日間(特徴量の計算に必要なため。確認期間・最終確認期間では該当しない) |

### 合格基準をこの形にした理由

- 探索期間(1年分)ですら日単位の検定は有意にならなかった。確認期間(約7か月)で有意性を合格基準にすると、効果が本物でも落ちる可能性が高い
- そこで、統計的な有意性ではなく「探索・確認・最終確認の3つの期間で、前後半とも同じ向きの結果が出るか」で判定する
- 効果が無い場合でも、1段階を偶然通過する確率は約2割と見積もった(探索期間の日ごとのばらつきからの概算)。2段階とも偶然通過する確率は数%程度
- 両段階を通過しても、統計的に証明されたことにはならない。前向き検証で、少額の実運用で確かめることを前提とする
