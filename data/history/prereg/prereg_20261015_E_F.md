## 1. 候補の由来

SMC/ICT系の手法(流動性の回収 → 構造の変化 → FVGへの戻りでエントリー)を紹介する動画の主張を、SAR転換に当てはめて探索期間(2024-10-01〜2025-09-30)で検証した。

- 「流動性の回収」は次のように定義した。左右k本のフラクタルで確定した直近のスイング高値(安値)を、ヒゲで上抜け(下抜け)し、終値で内側に戻した足。スイングは右k本が確定した時点で使えるものとし、最初に抜かれた時点で消費する
- 「構造の変化」は15分足のSAR転換(N=1)で代用した
- 試した組み合わせは約150通り(k=2/3/5/8、直前の窓W=4/8/16/32、決済方法3種、FVGエントリーの有無、24hトレンドとの順張り限定)
- 主な結果:
  - SAR転換の直前にスイープがあっても、転換の成績は良くならなかった。スイングが大きい(k=5・8)ほど、スイープ直後の転換は**むしろ悪かった**(例:k=8、W=4で転換→次の転換の期待値 −0.201%、スイープなしは −0.050%)
  - 動画どおりの形(転換足の終値で入り、SLをスイープのヒゲ先、TPを2R)は12通りすべて手数料後マイナス
  - FVGまでの戻りを待つ形は12通り中、前半・後半ともプラスになったのは1通り(候補E)だけで、近い設定(W=4・16)はマイナス
  - 24hトレンドと同じ方向の転換に限っても、スイープありの転換は12通り中11通りで後半マイナス
- 候補E・Fはどちらも総当たりで見つけたもので、統計的には確立していない。確認期間では「方向が再現するか」を見る

## 2. 候補E:動画どおりの形(スイープ → SAR転換 → FVGへの戻りで指値)

| 項目 | 内容 |
|---|---|
| 流動性の回収 | k=3。SAR転換足を含む直前8本(W=8)の中に、転換と逆側のスイープがあること(下転換なら高値側、上転換なら安値側) |
| FVG | スイープ足から転換足までの間にできた、転換方向の最新のFVG。ショートは「j足の高値 < j−2足の安値」で、エントリー価格はj足の高値。ロングは「j足の安値 > j−2足の高値」で、エントリー価格はj足の安値 |
| エントリー | 転換足の翌足から16本以内に、価格がエントリー価格まで戻ったら指値で約定。戻る前にTPに届いた場合と、16本以内に戻らなかった場合は見送り |
| エグジット | SLは、スイープ足から転換足までの最高値(ロングは最安値)の0.05%先。TPはSL幅の2倍(2R)。約定した足ではSLだけを判定し、翌足以降は高値・安値で判定。同じ足で両方に届いたらSLが先。SL幅が0.05%以下のものは除外 |
| 探索期間の成績(参考) | 178件、手数料後+0.040%(前半+0.049% / 後半+0.033%)。勝率37%、平均SL幅0.52%。日単位の片側t検定 p=0.298、上位5件を除くと−0.063% |

## 3. 候補F:大きなスイングのスイープ直後のSAR転換を、ダマシとみなして逆に入る

## 4. 評価方法と合格基準

候補C・Dと同じ。

| 項目 | 内容 |
|---|---|
| 主指標 | 手数料(往復0.05%)控除後の期待値/回 |
| 合格基準(確認期間・最終確認期間で共通) | 手数料後の期待値 > 0、かつ期間を前半・後半に分けて両方で手数料後の期待値 > 0 |
| 前半・後半の境界 | 確認期間:2026-01-15 00:00 UTC。最終確認期間:2026-07-02 00:00 UTC |
| 参考指標(判定に使わない) | 勝率、日単位の片側t検定、上位5件を除いた期待値、候補Eの平均SL幅 |
| 評価の順番 | 確認期間で1回だけ評価 → 合格した候補だけ最終確認期間で1回だけ評価 → 両方に合格した候補だけ前向き検証へ |
| 不合格の扱い | その候補は打ち切る。確認期間・最終確認期間のデータを見ながら k・W・決済方法を調整し直さない |
| データの扱い | 特徴量は評価期間の終わりより前のデータだけで計算する。期間の開始前のデータはスイングの検出に使ってよい |

### 事前の見立て

- 候補Eは、近い設定がマイナスの中で1つだけプラスになったもので、偶然の可能性が高いと見ている。動画の主張を確かめるために登録する
